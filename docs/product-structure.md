# سند ساختار محصول (Product Structure)

## ساختار دایرکتوری‌ها
پروژه از بخش‌های اصلی زیر تشکیل شده است:

- `src/components/`: شامل تمامی کامپوننت‌های عمومی و قابل استفاده مجدد سایت (مثل Navbar, Hero, TrustBar, CustomCursor).
- `src/admin/`: پنل مدیریت سایت با رابط کاربری مجزا که شامل تب‌های مختلف (نظیر Overview, HeroCms, Products و...) برای مدیریت محتوای سامانه است.
- `src/context/`: شامل `DataContext.tsx` که مدیریت State های اصلی (پروژه‌ها، محصولات، مقالات و تنظیمات) را بر عهده دارد.
- `src/types.ts`: تعریف تایپ‌ها و اینترفیس‌های TypeScript برای یکپارچگی داده‌ها.
- `public/images/`: محل ذخیره تصاویر ایستا و بنرها (تصاویر بدون کپی‌رایت و به صورت Local لود می‌شوند).

## جریان داده (Data Flow)
داده‌ها در حال حاضر از طریق `DataContext` بین پنل ادمین و وب‌سایت عمومی به اشتراک گذاشته می‌شوند تا تغییرات ادمین فوراً در سایت منعکس گردد.
