# سند دیزاین (Design Document)

## هویت بصری
- **سبک طراحی (Design Language):** لوکس، صنعتی، مینیمال با استفاده گسترده از افکت **Glassmorphism** (پنل‌های شیشه‌ای نیمه‌شفاف).
- **رنگ‌های سازمانی:** 
  - رنگ اصلی (Primary): سرمه‌ای (`#003F86`)
  - رنگ مکمل (Secondary/Accent): نارنجی/طلایی (`#FF9F14`)
  - رنگ‌های خنثی: خاکستری تیره (`#0f172a`) و سفید شفاف.

## تایپوگرافی
- فونت اصلی سامانه: **استعداد (Estedad)** با وزن‌های مختلف (Regular, Medium, Bold, Black).

## المان‌های ویژه UI/UX
- **Custom Cursor:** استفاده از نشانگر موس اختصاصی با افکت Mix-blend و بزرگ‌نمایی (Scale) در هنگام هاور روی دکمه‌ها و لینک‌ها.
- **Hero Section:** استفاده از اسلایدشوی محوشونده (Crossfade) برای تصاویر با کیفیت 8K که هر ۵ ثانیه تغییر می‌کنند.
- **Navbar:** طراحی به صورت کپسولی و شناور با منوهای شیشه‌ای و آیکون‌های متحرک.
