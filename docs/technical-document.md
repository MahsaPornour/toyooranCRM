# سند فنی (Technical Document)

## معرفی
این مستند شامل جزئیات فنی پیاده‌سازی پروژه «طیوران صنعت پویا» می‌باشد.

## تکنولوژی‌های استفاده شده
- **هسته اصلی:** React 18 
- **محیط اجرا و بیلد:** Vite
- **زبان برنامه‌نویسی:** TypeScript (با رعایت تایپ‌های سخت‌گیرانه در `src/types.ts`)
- **استایل‌دهی:** Tailwind CSS (طراحی ریسپانسیو و Mobile-First)
- **انیمیشن‌ها:** Framer Motion (`motion/react`) جهت اعمال افکت‌های ورودی، اسکرول و ترانزیشن‌های بین کامپوننت‌ها
- **آیکون‌ها:** Lucide React

## ساختار اجرایی
پروژه به صورت Single Page Application (SPA) توسعه یافته و از سیستم Context API برای مدیریت State های سراسری بهره می‌برد.
